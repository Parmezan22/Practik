# Система записи на приём — медицинская клиника

Учебный проект на **C# Windows Forms (.NET Framework 4.7.2)** с базой данных **SQLite**.
Совместим с Windows 7 SP1 и новее.

## Что уже готово (Этап 1)

| № | Требование | Где находится |
|---|------------|---------------|
| 1 | Проект WinForms + SQLite + миграции | `MedClinic/Data/Migrations.cs`, `DatabaseInitializer.cs` |
| 2 | Модели User, Doctor, Service, Appointment | `MedClinic/Models/` |
| 3 | Репозитории для каждой таблицы | `MedClinic/Repositories/` |
| 4 | Форма входа (SHA256) | `MedClinic/Forms/LoginForm.cs` , `Services/PasswordHasher.cs` |
| 5 | Разграничение ролей | `Services/Permissions.cs`, `Forms/MainForm.cs` |
| 6 | Логирование Serilog | `Services/LogConfig.cs` |
| 7 | Конфигурация appsettings.json | `MedClinic/appsettings.json`, `Services/AppConfig.cs` |

Дополнительно сделано: таблица связи `AppointmentServices` (несколько услуг в одной записи),
главное окно с меню, вкладками, карточками-счётчиками и строкой состояния.

## Как проверить этап 2

1. Войдите как **manager / manager123** → вкладка «Записи» → «Новая запись».
2. Выберите врача, основную и дополнительные услуги — внизу считается итог по цене и времени.
3. Нажмите «Записать на приём». Повторите попытку на то же время — появится сообщение,
   что время занято.
4. Войдите как **client / client123**: кнопка «Отменить запись» работает только для записей,
   созданных этим клиентом; «Завершить приём» недоступна.
5. Вкладка «Статистика»: выберите период и нажмите «Рассчитать» — появятся карточки
   среднего, медианы, дисперсии, СКО и таблица по дням.

## Как проверить этап 3

1. Войдите как **manager / manager123** → «Отчёты» → «Отчёт за период» →
   выберите период и нажмите «Построить». Внизу появятся число записей,
   сумма и средний чек.
2. Нажмите «В Excel», сохраните файл и откройте его — книга содержит шапку,
   таблицу, итоговую строку, автофильтр и закреплённые заголовки.
3. Нажмите «Печать» — откроется предварительный просмотр; из него можно
   отправить отчёт на принтер.
4. Нажмите «Курсы валют» — загрузятся курсы ЦБ РФ (нужен интернет).
   Отключите сеть и нажмите «Обновить»: появится понятное сообщение об ошибке.
5. Вкладка «Статистика» → «Рассчитать»: справа от таблицы строится диаграмма
   числа записей по дням.
6. Войдите как **admin / admin123** → «Администрирование» → «Пользователи»:
   добавьте пользователя, измените роль и пароль, попробуйте удалить самого
   себя или последнего администратора — операция будет заблокирована.

## Как проверить новые возможности

1. На главной странице щёлкните по карточке «Записей сегодня» — откроется журнал
   с включённым фильтром «Только сегодня». Остальные карточки открывают свои разделы.
2. Нажмите **F1** — откроется встроенная справка. Кнопка «Открыть руководство»
   запускает полный файл `docs\Руководство_пользователя.md`.
3. Создайте запись с длительной услугой (например, УЗИ — 40 минут) на 10:00,
   затем попробуйте записать другого пациента к тому же врачу на 10:15.
   Программа должна сообщить, что интервал 10:15–10:55 занят.
4. Создайте запись на 19:30 с услугой длиннее 30 минут — форма предупредит,
   что приём выходит за 20:00.
5. Меню «Файл» → «Резервная копия базы…» (Ctrl+B), сохраните файл и убедитесь,
   что он открывается в DB Browser for SQLite.
6. Задайте в фильтрах заведомо пустой период — в таблице появится подсказка
   «Записей не найдено. Измените фильтры…».

## Запуск

1. Откройте **Visual Studio 2019** (или 2022) с рабочей нагрузкой
   «Разработка классических приложений .NET».
2. Меню **Файл → Открыть → Проект или решение** → выберите `MedClinic.sln`.
3. Дождитесь восстановления пакетов NuGet (правый клик по решению → «Восстановить пакеты»,
   если автоматически не сработало).
4. Нажмите **F5** (Запуск).

При первом запуске автоматически:

- создаётся файл базы `bin\Debug\Data\clinic.db`;
- применяются миграции схемы;
- добавляются тестовые врачи, услуги, три записи и четыре пользователя;
- создаётся журнал `bin\Debug\Logs\clinic-ДАТА.log`.

## Сборка, тесты и релиз

Основные пакеты NuGet: Dapper 2.1.28, Microsoft.Data.Sqlite 3.1.32,
Newtonsoft.Json 13.0.3, Serilog 2.12.0, EPPlus 4.5.3.3, ScottPlot.WinForms 4.1.74.
Тестовый проект использует xUnit 2.9.2 и Microsoft.NET.Test.Sdk 17.11.1.

```powershell
# Сборка Debug
& "C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe" `
    "MedClinic.sln" /t:Build /p:Configuration=Debug /v:m

# Сборка Release
& "C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe" `
    "MedClinic.sln" /t:Build /p:Configuration=Release /v:m

# Модульные тесты (81 проверка)
dotnet vstest "MedClinic.Tests\bin\Debug\net472\MedClinic.Tests.dll"

# Публикация: сборка Release, папка dist\MedClinic-1.0.0 и ZIP-архив
powershell -ExecutionPolicy Bypass -File scripts\Publish-Release.ps1
```

Готовая программа лежит в `MedClinic\bin\Release`. Для переноса на другой
компьютер проще всего запустить скрипт публикации: он соберёт Release,
скопирует программу, библиотеки, настройки и документацию в `dist\MedClinic-1.0.0`
и упакует всё в `dist\MedClinic-1.0.0.zip`. Папки `Data` и `Logs` в пакет
не входят — они создаются при первом запуске.

## Где посмотреть базу данных

SQLite-файл можно открыть бесплатной программой **DB Browser for SQLite**
(https://sqlitebrowser.org) — раздел «Данные».

SQL Server для этого проекта **не нужен**: SQLite — это встроенная база в одном файле,
она не требует установленного сервера.

## Возможные проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| «Не удалось восстановить пакеты» | Нет доступа к nuget.org. Проверьте интернет, затем Сервис → Параметры → Диспетчер пакетов NuGet → Источники пакетов (должен быть nuget.org). |
| `Unable to load DLL 'e_sqlite3'` | Не скопировалась встроенная библиотека SQLite. Удалите папку `bin` и `obj`, пересоберите решение (Сборка → Пересобрать). |
| «Файл базы занят» | Закройте DB Browser for SQLite и перезапустите приложение. |
| Ошибка «Система не поддерживает .NET Framework 4.7.2» | Установите .NET Framework 4.7.2 с сайта Microsoft на Windows 7 SP1. |
| Кириллица в коде отображается «кракозябрами» | Файлы сохранены в UTF-8. В проекте задан `<CodePage>65001</CodePage>`, пересоберите решение. |
