# Руководство пользователя

**Система записи на приём — медицинский центр «Здоровье+»**
Версия 1.0.0, платформа .NET Framework 4.7.2 (Windows 7 SP1 и новее)

---

## 1. Назначение программы

Программа автоматизирует работу регистратуры медицинского центра:

- ведение справочников врачей и услуг;
- запись пациента на приём к врачу (в том числе сразу на несколько услуг);
- отмена записи и отметка о завершении приёма;
- поиск записей по периоду, врачу и статусу;
- отчёт «Записи за период» с итоговой суммой, экспортом в Excel и печатью;
- статистика загрузки клиники с диаграммой;
- просмотр официальных курсов валют Центрального банка РФ;
- управление учётными записями пользователей (для администратора).

Все данные хранятся в одном файле SQLite на компьютере. Интернет нужен только
для загрузки курсов валют; остальные функции работают без сети.

## 2. Системные требования

| Компонент | Требование |
|-----------|------------|
| Операционная система | Windows 7 SP1 / 8.1 / 10 / 11 |
| Платформа | .NET Framework 4.7.2 |
| Экран | от 1280 × 720, рекомендуется 1366 × 768 |
| Диск | около 100 МБ свободного места |
| Интернет | только для раздела «Курсы валют» |
| Дополнительно | ничего устанавливать не нужно: SQLite встроена в программу |

## 3. Запуск программы

1. Распакуйте архив `MedClinic-1.0.0.zip` в удобную папку (или откройте
   собранную папку `MedClinic\bin\Release`).
2. Запустите файл **MedClinic.exe**.
3. При первом запуске автоматически создаются:
   - база данных `Data\clinic.db`;
   - начальные врачи, услуги и записи;
   - журнал событий `Logs\clinic-ГГГГММДД.log`.

Если Windows показывает предупреждение системы безопасности, нажмите
«Подробнее» → «Выполнить в любом случае».

## 4. Вход в систему

Введите логин и пароль, затем нажмите **«Войти»** (или клавишу Enter).

| Логин | Пароль | Роль | Возможности |
|-------|--------|------|-------------|
| admin | admin123 | Администратор | все разделы, включая пользователей и журнал |
| manager | manager123 | Менеджер | справочники, записи, отчёты, статистика |
| client | client123 | Клиент | просмотр и создание своих записей |
| guest | guest123 | Гость | только просмотр |

> **Важно.** После первого входа администратору следует сменить пароли
> учётных записей: раздел **«Администрирование» → «Пользователи»**.
> Пароли хранятся в базе только в виде хэша SHA256 и не отображаются.

При неверном пароле программа сообщает об ошибке и предлагает повторить попытку.
После пяти неудачных попыток подряд вход блокируется на 30 секунд.

## 5. Главное окно

Слева расположено меню, в центре — вкладки разделов. Меню и вкладки
синхронизированы: выбранный раздел отмечается галочкой в меню.

На вкладке **«Главная»** показаны карточки-счётчики:

- количество врачей и услуг;
- общее число записей;
- число записей на сегодня.

**Карточки кликабельны.** Щелчок по карточке врачей, услуг или всех записей
открывает соответствующий раздел. Карточка «Записей сегодня» открывает журнал
и сразу включает фильтр «Только сегодня». При наведении на карточку появляется
подсказка о её действии.

Внизу окна — строка состояния: текущий пользователь, роль, подсказка по
текущему разделу, дата и время, путь к файлу базы данных.

Недоступные роли разделы скрыты: например, гость не увидит отчёты и статистику,
а управление пользователями доступно только администратору.

**Быстрая справка.** Клавиша **F1**, пункт меню **«Справка» → «Быстрый старт»**
или кнопка «Справка и горячие клавиши» на главной открывают краткую инструкцию.
Внизу окна справки есть кнопка «Открыть руководство» — она запускает этот файл.

## 6. Справочник врачей

Раздел **«Справочники» → «Врачи»**.

- **Поиск** — по ФИО, специальности, телефону или кабинету. Введите текст
  и нажмите «Найти» (или Enter). Кнопка «Сброс» очищает поиск.
- **Сортировка** — щёлкните по заголовку столбца; повторный щелчок меняет
  направление. Текущая сортировка подписана под таблицей.
- **Страницы** — выберите 10, 20 или 50 строк; кнопки «Назад»/«Вперёд»
  переключают страницы.
- **Добавить / Изменить** — открывается форма. Поля с `*` обязательны:
  ФИО (минимум два слова, только буквы, пробел и дефис) и специальность.
  Телефон и кабинет можно не заполнять.
- **Удалить** — только для администратора. Если у врача есть записи на приём,
  удаление блокируется сообщением о ссылочной целостности: сначала нужно
  удалить или переназначить записи.

Двойной щелчок по строке открывает форму редактирования.

## 7. Справочник услуг

Раздел **«Справочники» → «Услуги»**. Работает так же, как справочник врачей.

Дополнительно у услуги есть:

- **цена** — от 0 до 1 000 000 рублей;
- **длительность** — от 5 до 480 минут.

Эти значения подставляются в форму записи и влияют на итоговую стоимость.
Услугу с записями удалить нельзя.

## 8. Запись на приём

Раздел **«Записи»** → кнопка **«Новая запись»** (также доступна в меню
«Записи» и на главной странице).

Порядок работы:

1. Введите **ФИО пациента**.
2. Выберите **врача**.
3. Выберите **основную услугу**.
4. При необходимости отметьте **дополнительные услуги** в списке с флажками.
5. Укажите **дату** (прошедшие дни недоступны) и **время**.
   Время предлагается с 08:00 до 19:30 с шагом 30 минут.
6. Проверьте итоговую строку: стоимость и общая длительность пересчитываются
   автоматически. Рядом показан реальный интервал приёма, например
   «09:00–10:00», а не только время начала.
7. Нажмите **«Записать на приём»**.

Занятость проверяется **с учётом длительности всех выбранных услуг**.
Например, УЗИ длится 40 минут: запись на 10:00 занимает время до 10:40,
поэтому другая запись на 10:15 к этому же врачу будет отклонена.
Касание границ конфликтом не считается: 10:40–11:10 и 10:00–10:40 совместимы.

Если приём заканчивается позже 20:00, форма предупреждает об этом красным
текстом и не сохраняет запись. Отменённые записи время не занимают.

### Отмена и завершение

- Кнопка **«Отменить запись»** доступна клиенту для **своих** записей,
  менеджеру и администратору — для любых.
- Кнопка **«Завершить приём»** доступна только менеджеру и администратору.
- Отменить завершённый приём или завершить отменённый нельзя.

## 9. Журнал записей

Раздел **«Записи»**. Таблица показывает дату, время, пациента, врача,
услугу и статус.

Фильтры:

- период «с — по»;
- флажок «Только сегодня» (даты блокируются);
- врач (включая «Все врачи»);
- статус (записан / отменён / завершён).

Строки подсвечиваются: отменённые — серые, завершённые — светло-зелёные.
Работают сортировка по заголовкам и постраничный вывод.

Если по выбранным фильтрам ничего не найдено, вместо пустой таблицы
появляется подсказка: «Записей не найдено. Измените фильтры или нажмите
„Новая запись“».

## 10. Отчёт «Записи за период»

Раздел **«Отчёты» → «Отчёт за период»** (менеджер и администратор).

1. Укажите период (по умолчанию — с начала текущего месяца по сегодня).
2. При необходимости выберите врача и включите флажок «Только завершённые».
3. Нажмите **«Построить»**.

В таблице отображаются дата, время, пациент, врач, услуга, статус и стоимость.
Внизу считается:

- общее число записей, число завершённых и отменённых;
- сумма по неотменённым записям;
- средний чек.

**Стоимость записи** = цена основной услуги + цены всех дополнительных услуг.
Отменённые записи в сумму не входят.

### Экспорт в Excel

Кнопка **«В Excel»** → выберите папку и имя файла. Создаётся книга `.xlsx`
с заголовком отчёта, периодом, таблицей, итоговой строкой, автофильтром
и закреплённой строкой заголовков. После сохранения программа предложит
открыть файл.

Если файл уже открыт в Excel, появится сообщение: закройте его и повторите.

### Печать

Кнопка **«Печать»** открывает предварительный просмотр. В нём можно:

- пролистать страницы;
- изменить масштаб;
- отправить документ на принтер.

Печатная форма содержит шапку клиники, название отчёта, период, врача,
таблицу, итоговую сумму и номера страниц. Лист — альбомной ориентации.

## 11. Курсы валют ЦБ РФ

Кнопка **«Курсы валют»** на вкладке отчётов (доступна также без построения отчёта).

- Программа загружает официальные курсы с сервиса `cbr-xml-daily.ru`.
- Показываются код, название, номинал, курс за номинал, курс за одну единицу,
  изменение в рублях и процентах.
- Рост курса выделяется зелёным, падение — красным.
- Кнопка **«Обновить»** повторяет запрос.

Если интернета нет или сервер не отвечает, появляется понятное сообщение,
а под таблицей — подсказка проверить подключение. Остальные разделы программы
продолжают работать.

## 12. Статистика и диаграмма

Раздел **«Отчёты» → «Статистика»** (менеджер и администратор).

1. Выберите период или нажмите «Текущий месяц» / «Прошлый месяц».
2. Нажмите **«Рассчитать»**.

Карточки показывают:

- всего записей за период;
- среднее число записей в день;
- медиану;
- дисперсию;
- среднее квадратическое отклонение (σ).

Справа строится столбчатая диаграмма числа записей по дням, слева — таблица
по дням. В расчёт входят все календарные дни периода, включая дни без записей;
отменённые записи не учитываются. Формулы подписаны в нижней строке экрана.

## 13. Управление пользователями

Раздел **«Администрирование» → «Пользователи»** (только администратор).

- **Поиск** — по логину или названию роли.
- **Добавить** — логин (3–32 символа: латиница, цифры, точка, дефис,
  подчёркивание), роль и пароль (не короче 5 символов) с повтором.
- **Изменить** — можно поменять логин и роль. Пароль меняется только если
  заполнить поля «Новый пароль» и «Повтор нового пароля»; пустые поля
  означают «оставить прежний пароль».
- **Удалить** — с подтверждением.

Защита от ошибок:

- нельзя удалить учётную запись, под которой вы работаете;
- нельзя удалить или лишить роли последнего администратора;
- свою роль изменить нельзя (поле роли заблокировано);
- логин должен быть уникальным.

## 14. Журнал событий

Меню **«Администрирование» → «Журнал событий»** открывает папку `Logs`.
Файлы называются `clinic-ГГГГММДД.log`. В журнал записываются входы,
ошибки, изменения данных и действия администратора.

## 15. Типичные сообщения и что делать

| Сообщение | Причина | Решение |
|-----------|---------|---------|
| «Неверный логин или пароль» | опечатка или другая раскладка | проверьте Caps Lock и раскладку |
| «Время занято» | у врача уже есть запись, перекрывающая интервал | выберите другое время с учётом длительности услуг |
| «Приём заканчивается в …, а клиника работает до 20:00» | выбранное время слишком позднее для набора услуг | выберите более раннее время или сократите набор услуг |
| «Не удалось создать резервную копию» | папка недоступна или файл занят | выберите другую папку и повторите |
| «Нельзя удалить врача: с ним связано записей…» | ссылочная целостность | сначала удалите/переназначьте записи |
| «Не удалось подключиться к серверу курсов валют» | нет интернета или блокировка | проверьте сеть, нажмите «Обновить» |
| «Не удалось сохранить файл Excel» | файл открыт в Excel | закройте файл и повторите |
| «Файл базы занят» | база открыта в DB Browser | закройте программу просмотра БД |
| «Система не поддерживает .NET Framework 4.7.2» | не установлена платформа | установите .NET Framework 4.7.2 |

Подробности ошибок всегда записываются в журнал `Logs`.

## 16. Резервное копирование

Все данные находятся в файле `Data\clinic.db`. Программа умеет делать
корректную копию базы даже во время работы.

**Создание копии**

1. Меню **«Файл» → «Резервная копия базы…»** (или **Ctrl+B**).
2. Выберите папку и имя файла. По умолчанию предлагается имя вида
   `clinic-backup-2026-11-19_14-30.db`.
3. Нажмите «Сохранить». Программа сообщит полный путь к копии.

Копию лучше хранить отдельно от рабочей базы: на флешке, сетевом диске
или в облаке. В журнал событий записывается, кто и когда сделал копию.

**Восстановление**

1. Закройте программу.
2. Замените файл `Data\clinic.db` сохранённой копией (переименуйте копию
   в `clinic.db`).
3. Запустите программу и проверьте данные.

Нельзя сохранить копию поверх работающей базы — программа предупредит об этом.
Ручное копирование при закрытой программе тоже допустимо.

## 17. Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| **F1** | встроенная справка «Быстрый старт» |
| **Ctrl+N** | новая запись на приём |
| **Ctrl+1** | справочник врачей |
| **Ctrl+2** | справочник услуг |
| **Ctrl+3** | журнал записей |
| **Ctrl+4** | отчёт за период |
| **Ctrl+5** | статистика |
| **Ctrl+6** | пользователи (только администратор) |
| **Ctrl+B** | резервная копия базы |
| Enter | выполнить основное действие (войти, найти, сохранить) |
| Esc | закрыть диалоговое окно без сохранения |
| Tab | перейти к следующему полю |
| Двойной щелчок по строке | открыть форму редактирования |

Горячие клавиши также подписаны рядом с пунктами меню и в окне справки.

---

Если программа ведёт себя неожиданно, закройте её, сохраните файл журнала
из папки `Logs` и обратитесь к администратору.
